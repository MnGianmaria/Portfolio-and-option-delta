# Portfolio Optimization and Option Delta Estimation

An empirical study of portfolio allocation and option delta estimation using Python.

## Overview

This project explores two applications of computational methods in finance:

- Portfolio optimization using absolute-deviation risk measures, with in-sample and out-of-sample evaluation.
- Option delta estimation using Random Forest and neural networks, compared with a Black-model benchmark.

## Methods and Tools

Python · pandas · NumPy · SciPy · scikit-learn · TensorFlow · Matplotlib
